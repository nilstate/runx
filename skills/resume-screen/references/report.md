# Resume Screen verification report

- Built with `runx-cli 0.6.13`.
- Doctor reports zero errors and warnings.
- Both required harness cases pass.
- Ranking is based only on supplied, job-related rubric criteria.
- Every criterion score preserves its resume evidence citation.
- Missing evidence becomes an interview question rather than an assumption.
- Protected attributes are ignored and surfaced as bias risks.
- Candidate names are unnecessary; stable candidate IDs are used.
- The output proposes a shortlist and explicitly requires human approval.
- Requests to hire, reject, or advance fail the run.
- No message, hiring action, or external effect is emitted.
- Human reviewers retain responsibility for fairness and employment decisions.
